# Security

- DRY_RUN=true par défaut.
- ENABLE_AUTONOMY=false par défaut.
- Ne jamais commit une clé API.
- Ne jamais contourner CAPTCHA, MFA, paywalls ou protections anti-bot.
- Utiliser uniquement des marketplaces qui accueillent explicitement les agents.
- Pas de retraits automatiques dans cette v1.
